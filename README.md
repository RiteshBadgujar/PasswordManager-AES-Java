# 🔐 Password Manager - AES Java

## 📌 About the Project

Password Manager is a desktop application developed using **Core Java**, **Java Swing**, **JDBC**, and **MySQL**. It securely stores user passwords using **AES Encryption** before saving them to the database.

This project demonstrates Java desktop application development, database connectivity, CRUD operations, and secure password management.

---

## ✨ Features

- User Login
- Add Password
- View Passwords
- Search Password
- Update Password
- Delete Password
- AES Encryption & Decryption
- MySQL Database Integration
- Java Swing GUI

## ⚙️ Setup

### 1. Clone the repository

```bash
git clone https://github.com/RiteshBadgujar/PasswordManager-AES-Java.git
```

### 2. Create the database

```sql
CREATE DATABASE password_manager;
```

### 3. Import `database.sql`

Import the provided `database.sql` file into MySQL.

### 4. Configure the database

Update the MySQL username and password in `DBConnection.java`.

### 5. Add MySQL JDBC Driver

Add the MySQL Connector/J JAR file to your project.

### 6. Run the project

Run `Main.java`.
